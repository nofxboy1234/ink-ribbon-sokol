# Pinned nightly toolchain

Run:

```sh
./toolchain/bootstrap.sh
```

This installs the pinned Zig and patched ZLS into versioned directories under
`~/.local/opt`, updates the existing `~/.local/bin/zig` and `zls` symlinks,
materializes the patched project dependencies under `.toolchain/deps`, and
regenerates the translate-c bindings in `src/generated`.

Upstream revisions, archive checksums, and all temporary Zig-nightly
compatibility changes are recorded in `bootstrap.sh` and `patches/`. Previous
project dependencies are moved to `.toolchain/backups`; previous versioned Zig
and ZLS installations are left in place for rollback.

The shdc revision is the one required by this sokol-zig revision. ZLS's
`known-folders`, `diffz`, and `lsp-kit` remain at the revisions in ZLS's own
manifest. Their independent development heads are newer, but are not API
compatible with this ZLS revision.

The patched ZLS reads `.toolchain/zls-build-config.json`, generated by the
bootstrap script, because this Zig nightly no longer supports ZLS's custom
build runner. `enable_build_on_save` is currently `false`: regular language
server diagnostics and the project import graph work, but compiler diagnostics
from incremental build-on-save do not. Run builds explicitly with `zig build`
until build-on-save is adapted to Zig's replacement build protocol.

Validated commands:

```sh
zig build test
zig build -Doptimize=safe
zig build -Doptimize=fast
zig build -Dtarget=wasm32-emscripten
```

Run an example natively:

```sh
zig build run-box3d
zig build run-cube
zig build run-triangle
zig build run-texcube
```

Select the equivalent WASM page with the same steps:

```sh
zig build run-box3d -Dtarget=wasm32-emscripten
zig build run-cube -Dtarget=wasm32-emscripten
zig build run-triangle -Dtarget=wasm32-emscripten
zig build run-texcube -Dtarget=wasm32-emscripten
```

The generated pages are also installed as
`zig-out/web/ink_ribbon_box3d.html` and
`zig-out/web/ink_ribbon_cube.html`, and
`zig-out/web/ink_ribbon_triangle.html`, and
`zig-out/web/ink_ribbon_texcube.html`.
