# Model loading: cgltf + Sokol + Zig

Run the native example with:

```bash
zig build run-model-loading
```

Run the WebAssembly version with:

```bash
zig build run-model-loading -Dtarget=wasm32-emscripten
```

## Division of responsibilities

Sokol is the renderer, not the model-file parser. This example follows the
architecture of Sokol's upstream `cgltf-sapp.c` example:

| Responsibility | Library |
|---|---|
| Load external files asynchronously | `sokol.fetch` |
| Parse the glTF document | `cgltf` |
| Decode standard PNG images | `stb_image` |
| Create GPU resources and draw | `sokol.gfx` |

The complete runtime flow is:

```text
backpack.gltf
      │
      │ sokol.fetch
      ▼
cgltf_parse()
      │
      ├── discovers vertices.bin
      ├── discovers diffuse.png
      └── discovers specular.png
                  │
                  │ sokol.fetch
                  ▼
        asynchronously loaded bytes
          │                   │
          │                   └── stb_image ──► sg.Image / sg.View
          └── sg.Buffer
                  │
                  ▼
             sg.Bindings
                  │
                  ▼
               sg.draw
```

The model and textures are no longer embedded in the executable. On WASM they
are separate HTTP requests; natively they are read from the same asset folder.

## Source-asset conversion

The LearnOpenGL download provides a Wavefront OBJ model, while `cgltf` reads
glTF. The offline converter therefore turns the source asset into a standard
glTF asset set:

```text
backpack.obj + backpack.mtl
              │
              ▼
tools/convert_backpack_obj.py
              │
              ├── backpack.gltf   scene, mesh and material description
              ├── vertices.bin    interleaved position/normal/UV data
              ├── diffuse.png     standard glTF image
              └── specular.png    standard glTF image
```

Regenerate those assets with:

```bash
python3 tools/convert_backpack_obj.py
```

Conversion is normal for a game asset pipeline. The important distinction is
that the application now loads and interprets glTF at runtime instead of
embedding a backpack-specific byte array in Zig code.

## Mesh representation

The generated vertex buffer has this interleaved 32-byte layout:

```text
position.xyz       normal.xyz         texture UV
[f32 f32 f32]      [f32 f32 f32]      [f32 f32]
```

The corresponding glTF accessors describe the offsets, types and vertex count.
`model_loading.zig` reads that metadata through `cgltf` and creates a Sokol
vertex buffer when `vertices.bin` finishes loading.

This model is non-indexed because the OBJ converter expands each OBJ corner's
separate position, normal and UV indices into one complete GPU vertex. A more
general glTF scene can also contain index buffers and multiple primitives.

## OpenGL/LearnOpenGL mapping

| LearnOpenGL concept | Sokol + Zig equivalent |
|---|---|
| Assimp model importer | `cgltf` for glTF |
| Image decoder | `stb_image` |
| `Mesh` | Buffer/bindings/material plus an element range |
| `Model` | glTF nodes, meshes, primitives and materials |
| VBO | `sg.Buffer` in `vertex_buffers` |
| EBO | `sg.Buffer` bound as `index_buffer` |
| VAO | `sg.Pipeline` vertex layout plus `sg.Bindings` |
| `glBufferData` | `sg.makeBuffer` |
| `glVertexAttribPointer` | `sg.PipelineDesc.layout` |
| OpenGL texture object | `sg.Image` and `sg.View` |
| Texture sampling parameters | `sg.Sampler` |
| `glUseProgram` | `sg.applyPipeline` |
| Bind buffers and textures | `sg.applyBindings` |
| Set uniforms | `sg.applyUniforms` |
| `glDrawArrays`/`glDrawElements` | `sg.draw` |

## C integration without `@cImport`

The project pins `cgltf` and `stb`, compiles their C implementations as a
static library, and checks in bindings generated by `zig translate-c`:

- `src/examples/generated/cgltf.zig`
- `src/examples/generated/model_image.zig`

`toolchain/bootstrap.sh` downloads the pinned revisions and regenerates both
bindings, following the same approach already used for Box2D and cimgui.

## Main files

- `src/examples/model_loading.zig` — asynchronous loader and renderer
- `src/examples/model_loading.glsl` — model lighting shader
- `src/examples/assets/backpack/backpack.gltf` — runtime scene description
- `tools/convert_backpack_obj.py` — source-asset converter
- `src/examples/c/cgltf.c` — cgltf implementation translation unit
- `src/examples/c/model_image.c` — small stb_image wrapper
